ミュージックタイピングができるwebページ．

Mac版のGaragebandのミュージックタイピングが，pcのキーボードを打つだけで音が鳴らせて，外部のキーボードとかを用意せずに音を確かめられるのが，（楽曲の耳コピなどをpcでする上で）手をpcから離さなくてよく，便利だな，と思ったので，それの類似品で「キーを昇降する機能がある」「midiの録音機能がある」ものをGoogle Geminiに作ってもらった．

pc用ページ：https://eug1ena.github.io/music_typing_app/for-pc.html
スマホ用ページ：https://eug1ena.github.io/music_typing_app/for-smartphone.html
